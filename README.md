## Try it in two commands

```
/plugin marketplace add t8jwscc7qy-sketch/foma-skills
/plugin install foma-skills@foma
```

Restart Claude Code in your project and just talk to it: it picks the right skill by itself.

## What is inside

| | |
|---|---|
| 🧭 **Plan and build** | `shaping`, `design-interview`, `planning`, `executing`: from a rough idea to done tasks |
| 🔍 **Do it carefully** | `tdd`, `debugging`, `reviewing`, `refactoring`, `committing`, `documenting` |
| 🧹 **Keep it tidy** | `groundwork`, `tidying`, `handoff`, `learning`, `skill-finder` |
| 🔧 **Tune and extend** | `tuning`, `writing-skills` |

Every skill that changes files shows the exact change first and waits for your "ok". Everything is open source (Apache-2.0).
